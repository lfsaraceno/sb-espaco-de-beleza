# Site SB Espaço de Beleza Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Site de uma página da SB Espaço de Beleza: abertura com o lírio em partículas 3D, história, 5 unidades com WhatsApp e "Como chegar", publicado como prévia no GitHub Pages.

**Architecture:** HTML estático com todo o conteúdo no markup (funciona sem JS, bom para SEO). `main.js` cuida de Lenis, GSAP e da abertura; o lírio 3D é um bundle esbuild (`assets/lirio3d.js`, global `Lirio3D`) carregado depois do conteúdo, com fallback para o lírio SVG desenhado (DrawSVG). Mesmo padrão do site irmão `../Site Dra Socorro`.

**Tech Stack:** HTML/CSS/JS, GSAP 3.15 (ScrollTrigger, DrawSVG), Lenis 1.3, Three.js 0.187 via esbuild 0.28, Node 26 (`node --test`), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-22-site-sb-design.md`

## Global Constraints

- Marca: "SB Espaço de Beleza". "Espaço Belíssima" só aparece como "antigo Espaço Belíssima" na história.
- Só fatos de `refs/FATOS.md` e da §9 do spec. Nenhum serviço, preço, número ou depoimento inventado.
- Horário: "Segunda a sábado, 8h às 19h" (igual para as 5 unidades).
- WhatsApp: `https://wa.me/<número>?text=Ol%C3%A1!%20Vim%20pelo%20site.` com os números da §9.
- Cores: `#140406`, `#4a0a12`, `#7a1424`, `#f3e9e1`. Fontes: Bodoni Moda + Manrope (Google Fonts).
- `prefers-reduced-motion`: sem 3D, sem Lenis, sem scrub; lírio SVG estático.
- Caminhos relativos em todo o HTML/CSS/JS (site roda em `/<repo>/`).
- WCAG 2.2 AA: contraste, foco visível, alvos ≥ 44px, `lang="pt-BR"`.
- `spikes/` não entra no deploy e não é base do código.

## Review Focus

1. Celular fraco / aba em segundo plano: 3D não pode travar o scroll nem drenar bateria — render pausa fora da tela e com `document.hidden`. Teste: Task 4 step de verificação no navegador.
2. WebGL indisponível ou bundle 3D com erro: abertura cai para o lírio SVG desenhado, nada fica em branco. Teste: Task 4, `?nogl` força o fallback.
3. Clique no botão fixo antes da abertura terminar: vai direto às unidades, sem esperar animação. Teste: Task 3.
4. Sem JavaScript: todo texto e links visíveis (nada começa com `opacity:0` no CSS). Teste: Task 6 (`tests/site.test.mjs` checa CSS) + navegador com JS desligado.
5. Número de WhatsApp errado numa unidade: manda cliente para a loja errada. Teste: Task 2, assert de cada número contra a tabela.
